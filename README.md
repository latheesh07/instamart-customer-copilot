# Instamart Customer Intelligence & Support Copilot

## Overview

Instamart Customer Intelligence & Support Copilot is an AI/ML capstone
project that combines data engineering, SQL analytics, customer
segmentation, customer lapse prediction, customer-support ticket
classification, policy retrieval, and a simulated refund-support agent.

The project uses synthetic/mock project data and a simulated LLM
interface. The refund agent is for demonstration only; it does not issue
real refunds or transfer money.

### Technologies

-   Python
-   pandas and NumPy
-   scikit-learn
-   SQLite
-   joblib
-   TF-IDF retrieval
-   PowerShell
-   GitHub

## Reproduce

Run commands from the repository root in PowerShell. Use Python 3 and
install the dependencies listed in `requirements.txt`.

``` powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Run the scripts in the order appropriate to the files present in `src/`.
The following commands reflect the project scripts used during
validation:

``` powershell
python src/validate_part_a.py
python src/customer_segmentation.py
python src/lapse_prediction.py
python src/ticket_triage.py
python src/compare_classification.py
python src/policy_rag.py
python src/evaluate_policy_rag.py
python src/refund_agent.py
```

Some scripts may depend on data, database, or state files generated by
earlier steps. Check each script's inputs and arguments before running
it. The refund-agent demonstration may require an order ID or other
input as described by the script.

## Limitations

-   Results are based on the project's available synthetic/mock data and
    evaluation cases.
-   Classification and lapse-prediction metrics are not guarantees of
    production performance.
-   The policy evaluation contains only **8** predefined questions. Two
    answers bypass the mock LLM with deterministic responses, so the
    evaluation does not demonstrate broad RAG reliability.
-   The mock LLM is not a live production language model.
-   The refund agent is a simulation and does not interact with a
    payment provider or issue real refunds.
-   Checkpoint persistence was checked, but full resume behavior was not
    verified.
-   Data leakage, drift, fairness, security, latency, and production
    monitoring require additional review before deployment.
